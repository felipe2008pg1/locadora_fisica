# 🎬 CineClássico - Landing Page de Locadora Física

> *"O Prazer de Escolher o Filme na Prateleira Voltou."*

O **CineClássico** é uma landing page estática, responsiva e totalmente em **HTML e CSS**, criada para promover a experiência de frequentar uma locadora de filmes física. Em uma era dominada por streaming, o projeto resgata o valor de garimpar prateleiras, folhear capas (Blu-ray, DVD e VHS) e trocar recomendações de cinema.

**Site publicado:** <https://felipe2008pg1.github.io/locadora_fisica/>

> Projeto de estudo. Endereço, telefone e Instagram exibidos na página são dados de exemplo.

## 🚀 Seções da Página

- **Navbar fixa:** links âncora para cada seção e botão de chamada para ação (*Visite a Loja*).
- **Hero:** título de impacto, texto de apresentação e dois botões (*Como Chegar* e *Ver Acervo*).
- **Explore Nosso Acervo:** quatro cards de categorias: *Clássicos & Cult*, *Ficção & Ação*, *Comédia & Família* e *Terror & Suspense*.
- **Como Funciona a Locação:** passo a passo em 3 etapas (visitar a loja, fazer o cadastro, levar para casa).
- **Localização e Contato:** endereço, horário de funcionamento, telefone e Instagram. O mapa é apenas um espaço reservado (placeholder visual), sem mapa interativo.
- **Rodapé:** direitos autorais e assinatura do projeto.

---

## 🛠️ Tecnologias

- **HTML5:** estrutura semântica da página (`index.html`).
- **CSS3:** estilização própria, sem frameworks (`style.css`): tema escuro em vermelho e preto, layout responsivo com Flexbox/Grid e rolagem suave via `scroll-behavior`.
- **Google Fonts:** Poppins e Bebas Neue (carregadas via CDN).
- **Font Awesome 6.4.0:** ícones (carregado via CDN).

O projeto contém apenas HTML, CSS, imagens e Markdown: sem JavaScript, Python, back-end, banco de dados ou etapa de build. As fontes e os ícones dependem de conexão com a internet.

## 💻 Como Executar Localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/felipe2008pg1/locadora_fisica.git
   ```

2. Entre na pasta:

   ```bash
   cd locadora_fisica
   ```

3. Abra o `index.html` no navegador (ou use a extensão **Live Server** do VS Code).
